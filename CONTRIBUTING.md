# Contributing

Thank you for contributing to hecate-propylaea.

## Development setup

1. Install [Rust](https://rustup.rs) (stable toolchain).
2. Clone this repository and run `cargo test`.
3. For UI/MCP changes in `hecate`, also install Node.js 22+ and run `make test`.

## Pull requests

- Target the `master` branch.
- Keep changes focused; include tests when behavior changes.
- Version bumps happen via GitHub Releases (`vX.Y.Z`), not direct commits to `master`.
